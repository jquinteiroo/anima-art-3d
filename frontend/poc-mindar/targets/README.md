# Arquivos de alvo MindAR

O modo Van Gogh da demonstração procura um arquivo opcional chamado `van-gogh.mind` nesta pasta.

Para criá-lo:

1. Baixe a imagem exata: https://images.metmuseum.org/CRDImages/ep/web-large/DP-42549-001.jpg
2. Compile em: https://hiukim.github.io/mind-ar-js-doc/tools/compile/
3. Baixe `targets.mind`, renomeie para `van-gogh.mind` e coloque nesta pasta.

**Alternativa sem alterar GitHub:** na página da demo selecione o arquivo `targets.mind` pelo campo de upload. O site usa o arquivo local no navegador para aquela sessão.

Evite publicar outros arquivos binários não licenciados. Esta imagem do Met está identificada como domínio público no registro 436535.
